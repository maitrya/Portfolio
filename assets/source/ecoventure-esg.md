| # Bonds, Returns and Securities           |                          |
|                                           |                          |
| While ESG factors can influence both      |                          |
| fixed income and equity risk-return       |                          |
| profiles, their impact differs. In        |                          |
| equities, strong ESG practices can        |                          |
| translate to better operational           |                          |
| efficiency, brand reputation, and         |                          |
| long-term growth, potentially leading to  |                          |
| higher returns. Conversely, poor ESG      |                          |
| practices can pose reputational risks and |                          |
| impact a company\'s ability to attract    |                          |
| capital.It is however much easier to      |                          |
| track these changes in equity as compared |                          |
| to fixed income.                          |                          |
|                                           |                          |
| Fixed income, primarily concerned with    |                          |
| creditworthiness and timely repayment,    |                          |
| sees ESG factors influencing default      |                          |
| risk. Strong ESG practices can indicate a |                          |
| more resilient issuer, potentially        |                          |
| lowering default risk and enhancing       |                          |
| returns. Conversely, poor ESG practices   |                          |
| might signal higher default risk,         |                          |
| potentially leading to lower returns.     |                          |
|                                           |                          |
| # Corporate vs. Sovereign Bonds           |                          |
|                                           |                          |
| Data acquisition and interpretation       |                          |
| differ for corporate and sovereign bond   |                          |
| ESG integration. Corporate bonds offer    |                          |
| more readily available ESG data through   |                          |
| public disclosures and sustainability     |                          |
| reports. Sovereign bonds, however,        |                          |
| present a challenge due to limited        |                          |
| standardized ESG reporting by             |                          |
| governments. Investors may rely on        |                          |
| third-party ratings or engage directly    |                          |
| with governments to assess ESG practices. |                          |
|                                           |                          |
| # Green bonds                             |                          |
|                                           |                          |
| The **premium** an investor pays for a    |                          |
| green bond compared to a similar          |                          |
| conventional bond issued by the same      |                          |
| issuer. In other words, a green bond      |                          |
| might have a slightly **lower yield**     |                          |
| than a traditional bond with the same     |                          |
| maturity and creditworthiness             |                          |
|                                           |                          |
| -   **Green Bonds:** These are debt       |                          |
|     instruments used to finance           |                          |
|     environmentally friendly projects     |                          |
|     like renewable energy, clean          |                          |
|     transportation, or sustainable        |                          |
|     buildings.                            |                          |
|                                           |                          |
| -   **Conventional Bonds:** These are     |                          |
|     regular bonds used to raise capital   |                          |
|     for various purposes, not necessarily |                          |
|     tied to environmental benefits.       |                          |
|                                           |                          |
| -   **Greenium:** When investors are      |                          |
|     willing to accept a slightly lower    |                          |
|     return in exchange for supporting     |                          |
|     environmentally friendly projects,    |                          |
|     they create a demand for green bonds. |                          |
|     This increased demand can lead to a   |                          |
|     greenium, meaning the issuer can      |                          |
|     raise capital at a slightly lower     |                          |
|     cost compared to a conventional bond. |                          |
|                                           |                          |
| There are a few reasons why investors     |                          |
| might be willing to accept a greenium:    |                          |
|                                           |                          |
| -   **Alignment with Values:** Some       |                          |
|     investors prioritize environmental    |                          |
|     sustainability and are happy to       |                          |
|     forego a small amount of return to    |                          |
|     support positive environmental        |                          |
|     impact.                               |                          |
|                                           |                          |
| -   **Potential Long-Term Benefits:**     |                          |
|     Strong ESG practices can lead to a    |                          |
|     more resilient company in the long    |                          |
|     run, potentially mitigating risks and |                          |
|     improving overall returns.            |                          |
|                                           |                          |
| -   **Regulatory Landscape:** Growing     |                          |
|     regulations and market pressure       |                          |
|     towards sustainability may make green |                          |
|     bonds more attractive investments     |                          |
|     over time.                            |                          |

|                        | influence ESG risk  |           |           |
|                        | assessment.         |           |           |

|                        | more susceptible to |           |           |
|                        | long-term           |           |           |
|                        | sustainability      |           |           |
|                        | issues like climate |           |           |
|                        | change or resource  |           |           |
|                        | scarcity. Investors |           |           |
|                        | in long-term bonds  |           |           |
|                        | need to consider    |           |           |
|                        | these factors and   |           |           |
|                        | an issuer\'s        |           |           |
|                        | transition plans    |           |           |
|                        | for mitigating      |           |           |
|                        | these risks.        |           |           |
|                        | Conversely,         |           |           |
|                        | short-term bonds    |           |           |
|                        | are less exposed to |           |           |
|                        | long-term ESG risks |           |           |
|                        | but may still be    |           |           |
|                        | impacted by sudden  |           |           |
|                        | regulatory changes  |           |           |
|                        | or social           |           |           |
|                        | disruptions.        |           |           |
|                        |                     |           |           |
|                        | Engagement with     |           |           |
|                        | fixed income        |           |           |

|                        | allowing for more   |           |           |
|                        | direct influence.   |           |           |
|                        | Fixed income        |           |           |
|                        | investors, as       |           |           |
|                        | creditors, rely on  |           |           |
|                        | dialogue and        |           |           |
|                        | collaboration.      |           |           |
|                        | Engagement          |           |           |
|                        | strategies for      |           |           |
|                        | fixed income may    |           |           |

|                        | issuers to improve  |           |           |
|                        | ESG practices,      |           |           |
|                        | advocating for      |           |           |
|                        | sustainable         |           |           |
|                        | business models, or |           |           |
|                        | influencing green   |           |           |
|                        | bond issuance       |           |           |
